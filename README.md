# ETH Zurich LRE Thesis Template

## Overview

This repository serves as a template for organizing and writing your semester project / thesis using LaTeX and Typst.

## LaTeX

Two options:
- Clone the repository and compile locally:
  ```bash
  git clone https://github.com/eth-lre/thesis-template.git
  cd thesis-template/latex/
  pdflatex main.tex # TODO: might need to run multiple times and bibtex too
  ```
- Or use [Overleaf template](https://www.overleaf.com/latex/templates/eth-zurich-lre-thesis-template/pvwbkqytmjqp)

## Typst

Two options:
- Clone the repository and compile locally:
  ```bash
  git clone https://github.com/eth-lre/thesis-template.git
  cd thesis-template/typst/
  typst compile main.typ
  ```
- Or upload `typst/` to [Typst online app](https://typst.app/).

This template is based on [ethz-iis-thesis](https://typst.app/universe/package/ethz-iis-thesis).

## Miscellaneous

- Master theses should be minimum 20 pages and maximum 50 pages, excluding references.
- You might need to attach [a declaration of originality](https://ethz.ch/content/dam/ethz/main/education/rechtliches-abschluesse/leistungskontrollen/declaration-originality.pdf)
